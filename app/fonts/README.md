# Local fonts

Unmodified Latin WOFF2 subsets of Inter, JetBrains Mono, and Newsreader
(normal and italic), retained from this portfolio's previous Google Fonts
export. Loading them through `next/font/local` keeps builds independent of
Google Fonts network access. Other scripts use the configured system fallback.

All three families use the SIL Open Font License 1.1; see [`font-licenses.txt`](../../public/font-licenses.txt).
The notices include the Inter copyright embedded in the retained binary
and the current upstream notice. Upstream license sources:

- https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt
